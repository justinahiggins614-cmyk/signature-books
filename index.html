📚 How to use The Signature Book Depository

Every book on these shelves is a finished, original Signature work — free, no login. Here is everything this site can do, in plain words.

🗂 The A–Z archive

The shelves live on the 📚 1 Million Archive tab: 🔎 Search matches titles, descriptions, and book IDs (a full ID like JAH-BOOK-000123 jumps that exact book to the top); 🎛 Filters narrow by genre and source; Sort orders by newest, title A–Z, or longest first; the A–Z letter row filters by the first letter of the title; 🖼 Covers / ☰ List switch views; 🎲 Random opens a surprise book; 🔎 Book Finder matches plain-words descriptions against the shelves' own catalog records — it never invents books.

📖 Opening a book

Tap any cover (or the 📖 Read button) to open the full record: cover, title, byline, genre/word/chapter chips, the description, ⛓ Source lineage (which network record seeded it, if any), and the full text.

📑 Chapters

The Contents list at the top of the full text jumps straight to any chapter. If you leave and come back to the same book on this device, it offers to resume where you left off.

🔊 Read aloud

🔊 Read aloud reads the whole book with the floating bar at the bottom; ⏹ Stop ends it. 📖 Reader mode gives a calm reading layout; A− / A+ resize the reading text.

⧉ Copy · ⬇ Download · ↗ Share

⧉ Copy text copies the full book text. ⬇ Download .txt and ⬇ .json save the book as files. 📄 Plain text opens a plain-text page. ↗ Share copies a link to the book, and ⧉ Cite copies a citation. Every book also has a stable link like ?book=JAH-BOOK-000123 that survives refresh and sharing.

💬 Ask about this book

The per-book Ask AI answers from the book's own text — it quotes and explains, and says plainly when something isn't covered.

⚠ Report problem

Copies a pre-filled problem report for the book (wrong title, missing content, broken link…) — paste it wherever you report issues.
